This project combined embedded software development with custom circuit board design to create a standalone, fully playable Blackjack simulator.

### Embedded Software
* Programmed the core Blackjack game logic, state machine, and dealer rules in **C++**.
* Flashed and deployed the software onto an **MSPM0** microcontroller.

### Hardware Integration
* **Custom PCB:** Designed and fabricated a custom printed circuit board to house the microcontroller and essential peripheral components.
* **User Interface:** Interfaced the microcontroller with external hardware inputs (buttons) for player actions and an LCD screen for real-time visual output of the game state.

**Technologies Used:** C++, MSPM0 Microcontroller, Custom PCB Design, LCD Interfacing, Embedded Systems.
