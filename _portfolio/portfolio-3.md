This project introduced state into my digital designs, allowing outputs to depend on the system's history and current input[cite: 2].

### Key Features
* Designed a synchronous finite state machine (FSM) for a flight attendant call system.
* Built a clock divider to derive a slow clock from the board's 100 MHz oscillator.
* Implemented a rising-edge detector that emits a single-cycle pulse when the input transitions from $0$ to $1$.
* Developed a time-multiplexed controller to drive four 7-segment displays from a single set of segment wires.

**Technologies Used:** Verilog, AI-Assisted Testbenches, Xilinx Vivado.
